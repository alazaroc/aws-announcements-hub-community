# Announcements Hub for AWS — Community

This is the public space for feedback, bug reports, and feature requests for **[Announcements Hub for AWS](https://news.playingaws.com)** — an unofficial community hub to explore, track, and discuss AWS announcements.

> The application source code is private. This repo exists solely for community interaction.

---

## What is Announcements Hub for AWS?

A free, ad-free, serverless web app that helps you:

- 🔍 **Explore** AWS announcements by service, category, and date
- 🗳️ **Vote** on the most impactful announcements
- 💬 **Comment** and discuss with the community
- 🤖 **Ask questions** in natural language using an AI assistant (powered by Amazon Bedrock)
- ⭐ **Save favorites** and track your engagement history

---

## How to contribute

### 🚨 Report a bug

Found something broken or unexpected? [Open a bug report](../../issues/new?template=bug_report.md)

### 💡 Request a feature

Have an idea to improve the app? [Submit a feature request](../../issues/new?template=feature_request.md)

### 💬 Start a discussion

Not a bug and not a feature request? Use [Discussions](../../discussions) for:

- General questions about how the platform works
- Ideas you want to explore before formalizing
- Sharing feedback or suggesting improvements to these guidelines

---

## Guidelines

- Be respectful and constructive
- Search existing issues before opening a new one
- Provide as much detail as possible (screenshots, steps to reproduce, etc.)
- This is a personal side project — responses may not be immediate, but everything is read
